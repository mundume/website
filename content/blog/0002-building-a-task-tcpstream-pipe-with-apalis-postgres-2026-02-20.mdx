# Building a Zero-Copy, Bounded, Backpressure-Aware JSON TCP Stream in Rust

In this guide, we'll build a production-grade TCP → JSON ingestion
pipeline in Rust with the following properties:

-   ✅ Zero-copy (no unnecessary allocations)
-   ✅ Hard global backpressure cap
-   ✅ Max connection limit
-   ✅ Per-connection JSON size limit
-   ✅ Exposed as `Stream<Item = Result<T, Error>>`

This design is suitable for ingestion pipelines, worker systems,
orchestrators, or high-throughput event receivers.

------------------------------------------------------------------------

# 1. Problem Statement

We want:

1.  A TCP listener.
2.  Clients send newline-delimited JSON (NDJSON).
3.  We deserialize into `T`.
4.  We expose everything as a `Stream`.
5.  We prevent:
    -   Unbounded memory growth
    -   Unlimited connections
    -   Oversized JSON payloads
    -   Silent backpressure failures

------------------------------------------------------------------------

# 3. Error Type

We define structured errors for safety and observability.

``` rust
#[derive(Debug)]
pub enum JsonListenerError {
    Io(std::io::Error),
    Json(serde_json::Error),
    FrameTooLarge,
    TooManyConnections,
}
```

This allows us to control resource usage.

-   `max_frame_bytes` → Maximum JSON size per message
-   `channel_capacity` → Backpressure buffer limit

# 5. Zero-Copy NDJSON Decoder

We implement a custom decoder using `BytesMut`.\
This avoids allocating `String` and avoids UTF-8 revalidation.

``` rust
use bytes::BytesMut;
use tokio_util::codec::Decoder;

struct NdjsonDecoder {
    max_len: usize,
}

impl Decoder for NdjsonDecoder {
    type Item = BytesMut;
    type Error = std::io::Error;

    fn decode(
        &mut self,
        buf: &mut BytesMut,
    ) -> Result<Option<Self::Item>, Self::Error> {
        if let Some(pos) = buf.iter().position(|b| *b == b'\n') {
            if pos > self.max_len {
                return Err(std::io::Error::new(
                    std::io::ErrorKind::InvalidData,
                    "frame too large",
                ));
            }

            let mut frame = buf.split_to(pos + 1);
            frame.truncate(pos);
            return Ok(Some(frame));
        }

        if buf.len() > self.max_len {
            return Err(std::io::Error::new(
                std::io::ErrorKind::InvalidData,
                "frame too large",
            ));
        }

        Ok(None)
    }
}
```

Why this is zero-copy:

-   `split_to` does not copy data
-   We deserialize directly from `&[u8]`
-   No `String` allocations

# 6. The Listener Stream Type

``` rust
use tokio::sync::mpsc;

pub struct JsonListenerStream<T> {
    receiver: mpsc::Receiver<Result<T, JsonListenerError>>,
}
```

We internally use a bounded `mpsc` channel to enforce backpressure.

------------------------------------------------------------------------

# 7. Binding the Listener

``` rust
use tokio::net::TcpListener;
use tokio::sync::Semaphore;
use std::sync::Arc;
use serde::de::DeserializeOwned;

impl<T> JsonListenerStream<T>
where
    T: DeserializeOwned + Send + 'static,
{
    pub async fn bind(
        addr: &str,
        config: JsonListenerConfig,
    ) -> Result<Self, std::io::Error> {
        let listener = TcpListener::bind(addr).await?;
        let (tx, rx) = mpsc::channel(config.channel_capacity);

        let semaphore = Arc::new(Semaphore::new(config.max_connections));

        tokio::spawn(run_accept_loop::<T>(
            listener,
            tx,
            semaphore,
            config,
        ));

        Ok(Self { receiver: rx })
    }
}
```

This:

-   Binds TCP
-   Creates a bounded channel
-   Applies connection limits via `Semaphore`

------------------------------------------------------------------------

# 8. Accept Loop with Max Connection Limit

``` rust
async fn run_accept_loop<T>(
    listener: TcpListener,
    sender: mpsc::Sender<Result<T, JsonListenerError>>,
    semaphore: Arc<Semaphore>,
    config: JsonListenerConfig,
)
where
    T: DeserializeOwned + Send + 'static,
{
    loop {
        match listener.accept().await {
            Ok((socket, _)) => {
                match semaphore.clone().try_acquire_owned() {
                    Ok(permit) => {
                        let tx = sender.clone();
                        tokio::spawn(async move {
                            handle_connection::<T>(
                                socket,
                                tx,
                                config.max_frame_bytes,
                            )
                            .await;
                            drop(permit);
                        });
                    }
                    Err(_) => {
                        let _ = sender
                            .send(Err(JsonListenerError::TooManyConnections))
                            .await;
                    }
                }
            }
            Err(e) => {
                let _ = sender
                    .send(Err(JsonListenerError::Io(e)))
                    .await;
            }
        }
    }
}
```

This ensures:

-   No more than `max_connections`
-   Excess connections are rejected safely

# 9. Connection Handler with Hard Backpressure

``` rust
use tokio_util::codec::FramedRead;
use futures::StreamExt;

async fn handle_connection<T>(
    socket: tokio::net::TcpStream,
    sender: mpsc::Sender<Result<T, JsonListenerError>>,
    max_frame: usize,
)
where
    T: DeserializeOwned + Send + 'static,
{
    let mut framed = FramedRead::new(
        socket,
        NdjsonDecoder { max_len: max_frame },
    );

    while let Some(frame) = framed.next().await {
        match frame {
            Ok(bytes) => {
                let parsed = serde_json::from_slice::<T>(&bytes)
                    .map_err(JsonListenerError::Json);

                if sender.send(parsed).await.is_err() {
                    break;
                }
            }
            Err(e) => {
                let _ = sender
                    .send(Err(JsonListenerError::Io(e)))
                    .await;
                break;
            }
        }
    }
}
```

Why this enforces backpressure:

-   `mpsc` is bounded
-   `send().await` blocks when full
-   TCP window shrinks naturally

# 10. Stream Implementation

``` rust
use std::pin::Pin;
use std::task::{Context, Poll};
use futures::Stream;

impl<T> Stream for JsonListenerStream<T> {
    type Item = Result<T, JsonListenerError>;

    fn poll_next(
        mut self: Pin<&mut Self>,
        cx: &mut Context<'_>,
    ) -> Poll<Option<Self::Item>> {
        Pin::new(&mut self.receiver).poll_recv(cx)
    }
}
```

Now your listener behaves like any other async `Stream`.

# 11. Example Usage

``` rust
#[derive(serde::Deserialize, Debug)]
struct MyMsg {
    id: u64,
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let stream = JsonListenerStream::<MyMsg>::bind(
        "127.0.0.1:5000",
        JsonListenerConfig {
            max_connections: 100,
            max_frame_bytes: 8 * 1024,
            channel_capacity: 1024,
        },
    )
    .await?;

    futures::pin_mut!(stream);

    while let Some(msg) = stream.next().await {
        println!("{:?}", msg);
    }

    Ok(())
}
```

Test with:

``` bash
echo '{"id":1}' | nc 127.0.0.1 5000
```
